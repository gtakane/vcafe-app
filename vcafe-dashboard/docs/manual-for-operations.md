# Vあっとホームカフェ 運営ダッシュボード 利用マニュアル

運営チーム向けの操作ガイドです。専門知識は不要です。

---

## 1. はじめに

### できること

| したいこと | 見る画面 |
| --- | --- |
| 今月の売上・ご帰宅数を知りたい | ダッシュボード |
| メイドの月次実績を比べたい | メイド実績 → 月次実績 |
| 特定のメイドのご帰宅を1件ずつ見たい | メイド実績 → 個別ログ |
| サービスの成長を数字で見たい | グロース指標 |
| 特定のユーザーを探したい・条件で絞りたい | ユーザーDB |
| 誰がどのメイドに通っているか見たい | メイド×ユーザー |
| 出勤状況・遅刻を確認したい | 勤怠 |

### ログイン

配布されたURLを開き、Googleアカウントでログインします。

権限は2種類あります。

- **運営管理者** … すべての画面を閲覧できます
- **メイド** … 「ダッシュボード」「メイド実績」「勤怠」のみ。**表示されるのは自分の実績だけ**です

見えない画面がある場合は権限の設定によるものです。管理者に連絡してください。

### 大事な前提

- **データは1時間ごとに更新**されます。画面右上に「最終同期」の時刻が出ます。たった今のご帰宅はまだ反映されていません
- **営業日は19:00〜翌2:00**です。深夜0時〜1時59分のご帰宅は**前日の営業日**として集計されます。7/21の23時と7/22の1時は、どちらも「7月21日」の実績です
- ユーザー名は分析用に置き換えられている場合があります。個人を特定する目的では使用しないでください

## 2. 画面共通の使い方

### 期間の指定

画面の上部で期間を選びます。「今日 / 7日 / 30日 / 今月」のボタンか、開始日・終了日を直接指定します。

> **ユーザーDBだけは期間指定がありません。** 登録時からの通算値を表示するためです。

### 並び替え

表の**見出しをクリック**すると並び替わります。もう一度クリックで昇順・降順が切り替わります。ピンク色になっている列が現在の並び替え基準で、▼が大きい順、▲が小さい順です。

### CSV出力

各表の右上の「CSV出力」でExcelなどに取り込めます。**画面に表示されている条件で絞り込まれた状態**が出力されます。

### 用語がわからないとき

ダッシュボード画面の下部に用語集があります。指標名の横の「？」マークにマウスを乗せても説明が出ます。

---

## 3. ダッシュボード

期間全体のサマリーです。

| 指標 | 意味 |
| --- | --- |
| ご帰宅数 | 期間内のご帰宅の合計。**滞在40分は2件分**として数えます（1枠20分のため） |
| 売上 | チケット代・コイン消費・予約料金の合計 |
| 実働時間 | メイドの合計お給仕時間。打刻がない場合は予定時刻で計算します |
| 記念撮影 | チェキの撮影枚数 |

---

## 4. メイド実績

### 月次実績タブ

メイド全員の月次成績を一覧で比較できます。月は右上のプルダウンで切り替えます。

主な列:

- **お給仕回数 / お給仕時間** … 出勤の回数と合計時間
- **遅刻回数 / 遅刻時間** … 遅刻時間は小数点第3位以下を切り捨てて表示します
- **ご帰宅数 / 平均ご帰宅数** … 平均はご帰宅数 ÷ お給仕時間（1時間あたり何名か）
- **プレゼント数 / プレゼント売上** … アイテムを贈られた回数と金額
- **記念撮影回数 / 記念撮影売上** … チェキの枚数と金額

### 個別ログタブ

**1件ずつのご帰宅明細**です。右上でメイドを選ぶと表示されます。

いつ・どのユーザーが・何分・どのチケットで・支払い方法は何か・チェキを撮ったか・アイテムを使ったかが分かります。

表の上に出るサマリーの読み方が少し特殊なので、ここだけ丁寧に説明します。

| 表示 | 意味 |
| --- | --- |
| **延べ滞在** | ユーザーごとの滞在時間を単純に足した値。**同時に3名まで着席できる**ため、実際の時間より大きくなります |
| **実接客** | 同じ時間帯の重なりを除いた、実際に接客していた時間。3名が同じ20分に同席していれば、延べ滞在60分でも実接客は20分です |
| **実お給仕** | 出勤していた時間（打刻ベース、未打刻は予定時刻） |
| **稼働率** | 実接客 ÷ 実お給仕。出勤時間のうち実際に接客していた割合です |

> **稼働率が100%を超えて⚠マークが出たら**、データの不具合の可能性があります。出勤時間より長く接客することは物理的にできないためです。メイド名と期間を控えて、システム担当に連絡してください。

## 5. グロース指標（管理者のみ）

サービス全体の成長を見る画面です。

| 指標 | 意味 | 見るポイント |
| --- | --- | --- |
| DAU / WAU / MAU | 1日 / 1週 / 1か月あたりの利用者数 | 実人数です。同じ人が何回来ても1名 |
| 定着率 | DAU ÷ MAU | 高いほど「毎日来てくれている」状態 |
| 新規登録者数 | 期間内に会員登録した人数 | |
| 新規課金転換率 | 新規登録者のうち期間内に有料ご帰宅をした割合 | 低いと初回体験に課題がある可能性 |
| 離脱率 | 前の期間に来ていた人のうち、今期間に一度も来なかった割合 | 上昇していたら要注意 |
| 空席率 | 空いている座席の割合 | 高いとシフトが過剰、低いと機会損失 |

**空席率の考え方**: メイド1時間の稼働で最大9名（3席 × 3枠）を受け入れられます。全メイドの合計お給仕時間 × 9 が受け入れ可能な最大枠で、そのうち実際に埋まった割合が占有率、空いた割合が空席率です。

## 6. ユーザーDB（管理者のみ）

全会員の**通算値**の一覧です。期間指定の影響を受けません。

### 探し方

1. **名前・会員IDで検索** … 検索窓に入力
2. **属性で絞る** … ランク・性別・課金の有無・登録日の範囲
3. **数値で絞る** … 「数値で絞り込み」で指標を選び、「以上」「以下」に数値を入れて「この条件で絞り込む」

数値の絞り込みは**複数の条件を重ねられます**。条件はボタンとして表示され、クリックすると解除できます。

> 例: 累計ご帰宅が100以上、かつ課金額(通算)が50000以下のユーザーを探す
> → 「累計ご帰宅」で下限100 → 絞り込む → 「課金額(通算)」で上限50000 → 絞り込む

### 個別の詳細を見る

**行をクリック**すると、そのユーザーのご帰宅明細が開きます。誰にいつ通っているかが1件ずつ分かります。詳細画面の中で期間を変えられます（初期表示は直近1年）。

### 主な列

- **累計ご帰宅** … 登録時からの通算のご帰宅数
- **課金額(通算) / 課金回数(通算)** … WEB版時代を含む全期間の課金
- **コイン残高 / リワードP残高** … 現在の残高
- **最大連続日数** … 連続で来店した最長日数

## 7. メイド×ユーザー（管理者のみ）

どのユーザーがどのメイドに何回ご帰宅したかの交差表です。担当の偏りや、特定メイドのファン層を把握できます。

---

## 8. 勤怠

シフトの予定と実績の一覧です。

- **メイド**・**状態**（遅刻のみ / 定時のみ / 未打刻あり）で絞り込めます
- 日付・メイド・実働・遅刻の各列で並び替えできます
- **遅刻**は予定開始時刻からの遅れです。小数点第3位以下は切り捨てます
- **未打刻**と表示される場合、打刻が記録されていません。実働時間は予定時刻で計算しています

管理者はこの下に「Discord勤怠申請」も表示されます。Discordで提出された申請の**確認用一覧**です。シフト本体には自動反映されないため、必要な修正は別途行ってください。

---

## 9. 困ったときは

| 症状 | 確認すること |
| --- | --- |
| 数字が古い | 右上の「最終同期」を確認。1時間以上前なら同期が止まっている可能性 |
| 今日のご帰宅が出ない | 同期は1時間ごと。直近の記録はまだ反映されていません |
| 深夜のご帰宅が前日に入っている | 仕様です。営業日は19:00〜翌2:00です |
| 見えない画面がある | 権限の設定によるものです |
| 稼働率に⚠が出る | データ不具合の可能性。メイド名と期間を控えて連絡してください |
| 数字が明らかにおかしい | 画面名・期間・対象（メイド名やユーザー名）・実際の表示値を控えて連絡してください |

問い合わせの際は**スクリーンショット**があると原因特定が早くなります。

---

## 10. 取り扱いの注意

- この画面には**ユーザーの課金額・来店履歴といった機微な情報**が含まれます。閲覧権限のない人に画面を見せないでください
- CSVを出力した場合、**そのファイルも同じ機微情報を含みます**。保存場所と共有範囲に注意してください
- ダッシュボードは**閲覧専用**です。ここでの操作が本番サービスのデータを書き換えることはありません
